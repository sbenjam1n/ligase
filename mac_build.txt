# macOS build for ligase~
#
# Easiest: run `make` from the repo root. The Makefile auto-detects Darwin and
# links all 15 sources in src/ into ligase~.pd_darwin.
#
# Equivalent direct command (matches the Makefile's Darwin path exactly):

gcc -Wall -O2 -dynamiclib -undefined dynamic_lookup \
  -I/Applications/Pd-0.53-2.app/Contents/Resources/src \
  -o ligase~.pd_darwin \
  src/ligase~.c src/envelope.c src/grain.c src/grain_delay.c src/grain_delay_stut.c \
  src/grain_delay_bencina.c src/grain_distortion.c src/grain_moogladder.c src/grain_fog.c \
  src/kiss_fft.c src/kiss_fftr.c src/reel.c src/splice.c src/perlin.c src/sphere.c
